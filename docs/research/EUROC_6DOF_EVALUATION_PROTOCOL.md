# EuRoC Independent 6-DoF Pose Evaluation — Phase 82

Status: independent offline evaluation implementation; **synthetic tests only**.
This work is separate from native stereo/IMU fusion in PR #81 and does not alter
the estimator or use publisher ground truth in visual odometry.

## Why this milestone matters

The original Phase 75 evaluator reports translation ATE and aligned
world-frame relative displacement only. A functioning orientation estimator
also requires independent attitude errors and full SE(3) relative-pose errors.
The Phase 82 evaluator therefore reads scalar-first, body-to-world quaternions
from the original EuRoC ground truth and native estimator trajectory, without
feeding truth into the estimator.

## Inputs

- Ground truth: original EuRoC MAV state_groundtruth_estimate0/data.csv,
  with nanosecond timestamp, position, and q_RS_S in columns 1–8.
- Estimated pose: exact header timestamp_ns,x_m,y_m,z_m,qw,qx,qy,qz.
  This is the full native trajectory generated by the Phase 81 replay.
- Both body origins must be identical and both quaternions must transform the
  IMU body into their respective world reference frames; no silent camera-to-IMU
  or NED/ENU conversion is performed.
- Inputs must have strictly increasing timestamps, finite values, and
  normalized quaternions. Duplicate times and invalid schemas are rejected.

## Algorithm / restrictions

1. Match estimated-to-ground-truth timestamps with explicit fixed offset,
   nearest one-to-one association and user-set tolerance. Never silently reuse
   ground truth samples, optimize an offset, or interpolate publisher truth.
2. Fit rigid **SE(3) no-scale** position alignment using the existing
   independent Phase 75 SVD implementation on the entire matched trajectory.
3. Apply the corresponding world rotation to estimated body-to-world
   orientations. Report absolute geodesic SO(3) orientation angle in degrees.
4. For each near-fixed-lag pair, express translation in the **initial body's
   local coordinate frame**, and compare the two relative rotations. These are
   complete SE(3) relative-pose errors, unlike Phase 75 world-frame
   displacement errors.
5. Report sample counts, overlap, match fraction, explicit timing parameters,
   translation ATE, orientation errors, relative translation/orientation
   statistics and input SHA-256 hashes.

The aligned ATE and absolute attitude values are **offline, full-window
evaluation** and cannot be presented as online estimator performance. The
relative-pose errors do not use global alignment to conceal drift, and metric
scale is never fitted. The initial gravity and world-yaw reference in Phase 81
remains physically unverified.

## Usage

Download and independently verify an original EuRoC MAV archive. After the
Phase 81 native replay produces a full active/shadow 6-DoF trajectory:

~~~bash
python3 -m pip install "numpy>=2.3,<3"
python3 -m unittest tests.test_euroc_pose_evaluation -v

python3 -m research.experiments.euroc_pose_evaluation \
  --ground-truth /data/EuRoC/MH_01_easy/mav0/state_groundtruth_estimate0/data.csv \
  --estimated /data/exports/MH_01_easy_active_estimated.csv \
  --sequence MH_01_easy \
  --frame-agreement same-imu-body \
  --output /data/exports/MH_01_easy_active_six_dof_metrics.json \
  --tolerance-ms 20 --relative-lag-s 1 \
  --min-pairs 10 --min-overlap-s 5
~~~

Run the same command separately on the shadow estimator trajectory and
on multiple prespecified source sequences. Both tools refuse to overwrite an
existing metrics output. Preserve a source archive verification record,
exact commit SHA, calibration/frame agreements and matched sampling counts.
